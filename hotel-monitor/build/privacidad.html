Política de privacidad

Última actualización: 13 de septiembre de 2026

Esta política explica cómo InnoApp trata la información utilizada por el asistente de WhatsApp de Hotel La Plazuela, diseñado para responder consultas operativas de socios autorizados.

Información que tratamos

  • Número de teléfono de WhatsApp del remitente.
  • Contenido de los mensajes enviados al asistente y sus marcas de tiempo.
  • Datos técnicos necesarios para entregar, proteger y diagnosticar el servicio.
  • Métricas agregadas del hotel, como ocupación, ingresos, tarifa media, cancelaciones y canales.

Finalidad

Usamos esta información para verificar que el remitente esté autorizado, interpretar sus preguntas, consultar métricas operativas agregadas y devolver una respuesta por WhatsApp. También podemos utilizar registros técnicos para prevenir abusos, solucionar errores y mantener la seguridad del servicio.

Proveedores que intervienen

Para prestar el servicio utilizamos proveedores tecnológicos, entre ellos Meta y WhatsApp para la mensajería, Anthropic para interpretar preguntas y redactar respuestas, Amazon Web Services para el alojamiento y MongoDB Atlas para la información operativa. Cada proveedor trata información conforme a sus propios términos y políticas.

El asistente está diseñado para compartir con el modelo únicamente la pregunta recibida y métricas agregadas. No pretende enviar nombres ni documentos de huéspedes. Los usuarios no deben incluir datos personales innecesarios en sus consultas.

Conservación y seguridad

La aplicación no conserva intencionalmente un historial propio de conversaciones. Los proveedores y los registros técnicos de infraestructura pueden mantener datos durante el tiempo necesario para operar, proteger y diagnosticar el servicio. Se aplican controles de acceso y medidas técnicas razonables para limitar el uso no autorizado.

Uso compartido y venta de datos

No vendemos información personal. Solo la compartimos con los proveedores necesarios para prestar el servicio, cuando exista una obligación legal o cuando sea necesario para proteger la seguridad y los derechos de las personas involucradas.

Derechos y eliminación de datos

Puedes solicitar acceso, corrección o eliminación de información escribiendo a innoappdigital@gmail.com. Para conocer el procedimiento, consulta las instrucciones de eliminación de datos.

Cambios en esta política

Podemos actualizar esta política cuando cambie el servicio o sus requisitos legales. La versión vigente se publicará siempre en esta dirección, indicando su fecha de actualización.
